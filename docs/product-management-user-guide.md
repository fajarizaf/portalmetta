# Panduan Pengguna - Manajemen Produk

## Akses Halaman

- Buka `Admin → Product Management`.
- Pastikan branch aktif sesuai dengan dropdown di sidebar.

## Group Produk

- Tambah Group: tombol "Tambah Group" → isi nama, parent, deskripsi → Simpan.
- Edit/Hapus Group: pada kartu group tekan "Edit" atau "Hapus".

## Produk

- Tambah Produk: tombol "Tambah Produk" → isi nama, pilih group, klasifikasi pembayaran → Simpan.
- Edit/Hapus Produk: tombol "Edit" atau "Hapus" pada baris produk.

## Spesifikasi Dinamis

- Kelola Specs: tekan "Kelola Specs" pada baris produk.
- Tambah Field: isi key, label, tipe, centang required bila wajib.
- Config JSON: isi opsi khusus (mis. dropdown options, checklist accessories dengan qty).

## Harga Produk

- Kelola Harga: tekan "Kelola Harga" pada baris produk.
- Tambah Harga: isi currency, base price, setup fee, pilih model harga.
- Config JSON: untuk discount atau tiered pricing.

## Pencarian & Filter

- Gunakan input "Cari produk..." dan filter model/group di atas tabel.

## Catatan

- Semua operasi berlaku untuk branch aktif saat ini.
- Pastikan format JSON pada Config valid (gunakan tanda kutip ganda dan struktur yang benar).
